# 2.3 读原理图与数据手册

> 本节目标：建立“板级原理图 → MCU 引脚 → 复用功能 → 寄存器/驱动”的追踪路径，不再靠猜引脚。

## 两类核心文档

- **Datasheet**：芯片电气特性、引脚定义、封装、绝对最大额定值、时序。
- **Reference Manual**：外设寄存器、工作模式、时钟、中断、DMA、启动细节。
- **Errata**：已知硬件缺陷和规避措施。
- **Board Schematic**：具体开发板如何连接、跳线、电源和外部器件。

很多“代码没问题但外设不工作”的情况，最后都能追到原理图或勘误表。

## 从原理图找引脚

以 NUCLEO-F411RE 的 LD2 为例：

1. 在原理图搜索 `LD2`。
2. 找到 LED 连接的网络标签，例如 `PA5`。
3. 查看 LED 是高有效还是低有效、限流电阻是多少。
4. 到 MCU 数据手册确认 PA5 的复用功能和电气特性。
5. 到 HAL/CubeMX 配置对应 GPIO。

关键不是记住 PA5，而是掌握这条追踪路径。

## 引脚复用

一个 MCU 引脚通常可以复用为：

- GPIO 输入/输出。
- USART TX/RX。
- I2C SCL/SDA。
- SPI SCK/MISO/MOSI。
- 定时器通道。
- ADC 输入。
- 调试接口。

配置外设时，要同时确认：

1. 引脚是否支持该复用功能。
2. 复用编号是否正确。
3. 是否需要外部上拉或特殊电路。
4. 是否与其他外设冲突。

## 电气与时序

数据手册中常被忽略的部分：

- 绝对最大额定值：超过可能永久损坏。
- 推荐工作条件：设计应工作在此范围。
- 输入高低电平阈值：3.3 V 器件不一定能可靠识别 1.8 V 信号。
- 输出驱动能力：能否直接驱动 LED 或另一颗芯片。
- 上电/复位时序：某些器件要求电源稳定后再释放复位。
- 通信时序：I2C 上升沿、SPI 时钟相位、UART 采样点。

## 勘误表

勘误表会列出芯片已知问题，例如某个外设在特定时钟下异常、DMA 请求丢失、低功耗唤醒失败。产品选型时应阅读勘误，至少确认有没有影响当前用法的条目。

## 读寄存器章节的方法

以 UART 为例：

1. 找到状态寄存器（SR）中的发送空、接收非空、错误标志。
2. 找到数据寄存器（DR）的读写语义。
3. 找到波特率寄存器（BRR）的计算公式。
4. 找到控制寄存器（CR1/CR2/CR3）中的使能位、中断位、DMA 位。
5. 找到中断向量和清除标志的方法。

不要只看 HAL 函数名。HAL 只是帮你写寄存器，出问题时仍然要回到手册。

## 常见坑

- 把开发板引脚丝印当 MCU 引脚号。
- 只看 Datasheet 不看 Reference Manual。
- 忽略复用功能冲突。
- 忽略外部上拉、晶振、复位和电源电路。
- 不读勘误表，遇到芯片级问题无法定位。
