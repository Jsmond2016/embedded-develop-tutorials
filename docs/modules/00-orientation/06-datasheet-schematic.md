# 0.6 如何阅读数据手册、原理图与错误码

> 本节目标：不再“照抄例程”，而是能从原理图确认连接、从数据手册确认时序和寄存器，再把信息翻译成代码。

## 读数据手册的顺序

不要从第一页开始逐页阅读。按任务导向查找：

1. **Features**：确认电压、接口、量程、精度和封装。
2. **Block Diagram**：理解内部模块和数据流。
3. **Pinout / Pin Description**：确认引脚功能、复用和电气类型。
4. **Electrical Characteristics**：确认绝对最大额定值、输入输出电平、功耗。
5. **Timing Characteristics**：确认建立时间、保持时间、最大时钟频率。
6. **Register Map**：确认配置位、状态位、数据格式和复位值。
7. **Application Information**：确认推荐电路、上拉电阻和去耦电容。

对于 MCU，还要重点看时钟树、启动模式、中断向量表、Flash 分区和调试接口。

## 读原理图

原理图不是“连线图”，而是电气关系的抽象。先找四类信息：

- **电源网络**：`3V3`、`5V`、`GND`，确认器件工作电压。
- **网络标签**：同名标签表示相连，即使图上没有画线。
- **上拉/下拉**：I2C 必须有上拉，按键需要明确默认电平。
- **去耦电容**：芯片电源脚附近通常需要 `100 nF`，不能省略。

例如，OLED 的 SDA/SCL 连接到 MCU 的哪个引脚，不能只看模块丝印，要沿着网络标签找到 MCU 引脚，再查该引脚是否支持 I2C 复用。

## 一个完整例子：AHT20

假设原理图显示：

- VDD 接 `3V3`。
- GND 接 `GND`。
- SDA 接 `PB7`，SCL 接 `PB6`。
- SDA/SCL 各有 `4.7 kΩ` 上拉到 `3V3`。

数据手册给出：

- I2C 地址为 `0x38`。
- 上电后需要等待至少 40 ms。
- 发送 `0xAC 0x33 0x00` 触发测量。
- 等待约 80 ms 后读取 6 个字节。
- 湿度和温度按 20 位数据换算。

驱动伪代码：

```c
uint8_t cmd[3] = {0xAC, 0x33, 0x00};
uint8_t raw[6];

i2c_write(AHT20_ADDR, cmd, sizeof(cmd));
delay_ms(80);
i2c_read(AHT20_ADDR, raw, sizeof(raw));

uint32_t humidity_raw = ((uint32_t)raw[1] << 16) |
                        ((uint32_t)raw[2] << 8) |
                        (raw[3] >> 4);
uint32_t temp_raw = (((uint32_t)raw[3] & 0x0F) << 16) |
                    ((uint32_t)raw[4] << 8) |
                    raw[5];

float humidity = (float)humidity_raw * 100.0f / 1048576.0f;
float temperature = (float)temp_raw * 200.0f / 1048576.0f - 50.0f;
```

这段代码的每一行都能在数据手册中找到依据。写驱动时，最好把页码或章节号记录在注释里。

## 错误码怎么读

芯片错误码通常分三类：

- **传输错误**：NACK、总线忙、超时、仲裁丢失。
- **状态错误**：器件未就绪、测量未完成、校准丢失。
- **数据错误**：CRC 失败、量程溢出、无效寄存器值。

不要把所有错误都返回成 `-1`。至少区分超时、参数错误、总线错误和器件错误，否则现场无法定位。

## 常见坑

- 把 5 V 器件直接接到 3.3 V GPIO，导致电平不兼容或损坏。
- I2C 缺少上拉，示波器上看到波形但通信失败。
- 把“典型值”当“保证值”，忽略温度和批次差异。
- 只读寄存器地址，不读时序和状态位。
- 忽略上电稳定时间，器件还没就绪就开始通信。

## 动手练习

选择你手边的传感器，完成一页“驱动信息卡”：

1. 工作电压与接口。
2. 引脚连接和上拉/去耦要求。
3. 器件地址。
4. 初始化命令。
5. 一次测量的完整时序。
6. 数据格式与换算公式。
7. 三个最可能出现的错误。

## 面试表达

> 我读传感器手册时会先确认电气特性和时序，再看寄存器。比如 AHT20 需要上电等待、触发命令、80 ms 转换时间和 20 位数据拼接；驱动里会区分 I2C 超时、NACK 和数据校验错误。
