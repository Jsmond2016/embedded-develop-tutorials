# 6.7 文档、BOM 与生产交付

> 本节目标：补齐一个嵌入式项目从代码到可生产所需要的文档和交付物。

## 核心文档

| 文档 | 作用 |
| --- | --- |
| README | 项目目标、构建、烧录、运行 |
| 架构说明 | 模块、数据流、线程/任务模型 |
| 引脚表 | 引脚、功能、电平、外设、冲突 |
| 协议文档 | 帧格式、字段、错误码、版本 |
| 测试记录 | 用例、环境、结果、已知问题 |
| BOM | 物料、型号、封装、替代料 |
| 生产测试规范 | 测试项、工装、判定标准 |
| 版本记录 | 固件/硬件/配置兼容性 |

## README 模板

````markdown
# 环境监测终端

## 硬件
- MCU: NUCLEO-F411RE
- 固件版本: 1.0.0
- 硬件版本: REV_A

## 构建
```bash
cmake -S . -B build -G Ninja
cmake --build build
```

## 烧录
```bash
openocd -f board/st_nucleo_f4.cfg -c "program build/app.elf verify reset exit"
```

## 已知问题
- 低电量时 Wi-Fi 重连较慢。
````

## 引脚表

| MCU 引脚 | 功能 | 外设 | 有效电平 | 备注 |
| --- | --- | --- | --- | --- |
| PA5 | GPIO 输出 | LED | 低 | 板载 LD2 |
| PC13 | EXTI | 用户按键 | 低 | 内部上拉 |
| PB6 | I2C1_SCL | OLED | - | 4.7 kΩ 上拉 |
| PB7 | I2C1_SDA | OLED | - | 4.7 kΩ 上拉 |

## 生产测试

```text
上电 -> 读取设备 ID -> 检查固件版本 -> 测试 LED/按键
-> 读取传感器 -> 测试无线连接 -> 写入唯一密钥 -> 打印测试结果
```

测试结果要绑定设备序列号，便于追溯。

## 可追溯性

- 设备序列号 ↔ 固件版本 ↔ 硬件版本。
- 生产批次 ↔ BOM/替代料。
- 测试记录 ↔ 工位/时间/操作员。
- 现场故障 ↔ 日志/复位原因/升级历史。

## 常见坑

- README 只有“运行 main”。
- 引脚表与代码不一致。
- BOM 没有替代料说明。
- 生产测试依赖人工判断。
- 设备没有唯一序列号。
- 现场问题无法对应到生产批次。

## 检查清单

- [ ] README 能让新人独立构建和烧录。
- [ ] 引脚表和代码一致。
- [ ] BOM 有型号、封装和替代料。
- [ ] 生产测试有明确判定标准。
- [ ] 设备序列号可追溯。
- [ ] 版本、硬件和配置兼容性有记录。
