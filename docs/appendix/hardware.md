# 硬件清单

## 必备

| 物品 | 建议 | 用途 |
| --- | --- | --- |
| STM32 开发板 | NUCLEO-F411RE | 主控、板载调试器 |
| USB 线 | 数据线，不是充电线 | 供电与调试 |
| 面包板 | 830 孔 | 搭建电路 |
| 杜邦线 | 公对公/公对母 | 接线 |
| 万用表 | 基础款 | 电压、通断、电流 |
| USB-TTL | 3.3 V/5 V 可选 | 串口日志 |
| LED/电阻 | 多种阻值 | GPIO 实验 |
| 按键 | 轻触开关 | 输入、消抖 |

## 第 2 部分推荐

- I2C OLED（SSD1306）。
- AHT20 或 BME280。
- 10 kΩ 电位器。
- 4.7 kΩ 上拉电阻。
- 逻辑分析仪（8 通道）。

## 联网与 Linux

- ESP32-S3 开发板。
- Raspberry Pi 4B/5（2 GB+）。
- 高质量 5 V 电源。
- 16 GB+ microSD 卡。

## 进阶可选

- 示波器或 USB 示波器。
- CAN 收发器模块。
- RS-485 模块。
- 电机驱动与编码器。
- 电流探头/功率计。
- 防静电垫和镊子。

## 采购原则

- 先买当前阶段需要的，不囤模块。
- 优先有数据手册、原理图和成熟驱动的器件。
- 开发板优先板载调试器，减少接线变量。
- 保留购买链接和丝印照片。
- 不买来源不明的“万能套件”。

## 安全

- 只做 3.3 V/5 V 低压实验。
- 断电改线。
- 不直接驱动电机、继电器、市电。
- 逻辑分析仪与目标板共地。
- 发现发热、异味、冒烟立即断电。
