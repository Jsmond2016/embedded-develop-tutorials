# 面试题库速查

## C 语言

1. `volatile` 的作用？
   - 防止优化访问；不保证原子性。
2. `static` 的三种用法？
   - 局部变量延长生命周期；全局变量/函数限制链接可见性。
3. 指针和数组的区别？
   - 数组有确定存储；函数参数会退化，需要长度。
4. 结构体为什么有填充？
   - 对齐要求；字段顺序影响大小。
5. 什么是未定义行为？
   - 标准不规定结果，如越界、空指针、有符号溢出。
6. `malloc` 在嵌入式中的风险？
   - 碎片、延迟不确定、失败处理复杂。

## MCU

1. 中断服务程序原则？
   - 短小、不阻塞、清标志、投递事件。
2. 上电启动流程？
   - 向量表 → Reset_Handler → 初始化 → main。
3. HardFault 怎么查？
   - CFSR/HFSR/PC/LR/栈帧/Map/反汇编。
4. GPIO 推挽和开漏？
   - 推挽主动输出高低；开漏需上拉，适合 I2C。
5. PWM 频率如何计算？
   - `f_timer / (PSC+1) / (ARR+1)`。
6. ADC 采样时间为什么重要？
   - 高阻抗信号需要更长采样时间。

## RTOS

1. 任务和中断的区别？
   - 任务有栈、可阻塞；中断硬件触发、不可阻塞。
2. 队列、信号量、互斥量？
   - 传数据、发事件、保护资源。
3. 优先级反转？
   - 中优先级任务间接阻塞高优先级任务；用优先级继承。
4. 栈大小怎么定？
   - 栈高水位 + 最坏调用链 + 20–30% 余量。
5. 为什么 ISR 用 FromISR API？
   - 不阻塞、正确处理调度器状态。

## 通信

1. UART/I2C/SPI 怎么选？
   - 点对点、多从机低速、高速板内。
2. I2C 锁死怎么恢复？
   - 9 个时钟 + STOP，检查上拉和从设备。
3. TCP 可靠为什么还要重试？
   - 业务超时、半开连接、服务端失败。
4. MQTT QoS 1 会重复吗？
   - 会，需要去重。
5. OTA 如何防变砖？
   - A/B、签名、自检、回滚、恢复模式。

## Linux

1. 交叉编译是什么？
   - host 生成 target 架构程序，需要工具链和 sysroot。
2. 设备树作用？
   - 描述板级硬件，驱动通过 compatible 匹配。
3. 内核模块和用户程序区别？
   - 内核空间/用户空间，权限与隔离不同。
4. 启动流程？
   - BootROM → Bootloader → Kernel+DTB → Rootfs → init。
5. 服务起不来怎么查？
   - systemctl status、journalctl、strace、权限和依赖。
