# P2 裸机环境监测节点

## 目标

基于 STM32F411 + AHT20 + OLED 完成环境监测节点，要求主循环不阻塞。

## 功能

- 每 2 秒读取温湿度。
- OLED 显示当前值、状态和错误码。
- UART 命令：`status`、`interval 1000`、`reset`。
- 按键切换显示页面。
- LED 指示运行/错误状态。
- 看门狗保护。

## 硬件

| 模块 | 连接 |
| --- | --- |
| AHT20 | I2C1 PB6/PB7，3.3 V，4.7 kΩ 上拉 |
| OLED | 同 I2C1，地址不能冲突 |
| 按键 | PC13，内部上拉，低有效 |
| LED | PA5，低有效 |
| 串口 | USART2 PA2/PA3，115200 |

## 架构

```text
timer tick -> 采集状态机 -> 样本缓存 -> 显示状态机
                      -> UART 命令解析器
                      -> 健康检查/看门狗
```

不使用 `HAL_Delay()` 作为业务节奏。所有等待通过时间戳和状态推进。

## 验收

- 正常采集并显示。
- 拔掉传感器后显示错误，不崩溃。
- 串口命令可修改周期。
- 连续运行 24 小时无复位。
- 按键消抖不产生重复事件。
- 看门狗在死循环时能复位。

## 故障注入

1. 断开 SDA，观察 I2C 错误和恢复。
2. 把传感器地址改错，验证 NACK 处理。
3. 在主循环加入 `HAL_Delay(5000)`，观察看门狗。
4. 把显示缓冲区改小，验证边界检查。

## 交付物

- 原理图/接线表。
- 状态机图。
- 串口命令说明。
- 24 小时运行日志。
- 一次故障复盘。

## 面试表达

> 我把采集、显示和命令解析拆成非阻塞状态机，用时间戳驱动节奏。传感器失败时保留上次有效值并标记数据质量，避免把通信失败误报成 0。
