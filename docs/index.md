## 这门课解决什么问题

前端工程师并不缺编程能力，真正困难的是完成四次思维切换：

1. 从托管运行时切换到裸机与静态内存。
2. 从事件循环切换到中断、队列与 RTOS 调度。
3. 从浏览器调试切换到 GDB、寄存器和逻辑分析仪。
4. 从页面交付切换到可靠性、实时性和量产约束。

## 学习路线

| 阶段 | 周期 | 核心产出 |
| --- | ---: | --- |
| 转型认知与环境 | 1 周 | 点灯、串口输出、GDB 调试 |
| C 与底层思维 | 4 周 | 主机端 C 工具库 |
| MCU 与外设 | 5 周 | 裸机环境监测节点 |
| FreeRTOS | 4 周 | 多任务监测仪 |
| 通信与 IoT | 3 周 | MCU + 网关 + Web 仪表盘 |
| 嵌入式 Linux | 3 周 | Linux 边缘网关服务 |
| 工程化与量产 | 2 周 | 可交付的产品原型 |
| 求职与面试 | 1 周 | 简历、作品集与面试题库 |

> 建议每周投入 12–15 小时，动手时间不少于 60%。完整路线约 20–24 周；如果只冲 MCU 固件岗位，可压缩到 18 周左右。

## 推荐硬件

- 主控：`NUCLEO-F411RE`，预算替代为 `STM32F103C8T6 + ST-Link V2`
- 联网：`ESP32-S3`
- Linux：`Raspberry Pi 4B/5`，预算有限时使用 `QEMU`
- 工具：面包板、杜邦线、LED、按键、电阻、USB-TTL、万用表
- 外设：I2C OLED、AHT20/BME280、逻辑分析仪

::: warning 安全边界
本课程只进行低压直流实验。不要在没有隔离、保护和专业指导的情况下接触市电、高压、电机或大功率设备。
:::

## 学完后应具备的能力

- 能读懂数据手册和原理图中的关键部分，完成常见外设驱动。
- 能用裸机和 FreeRTOS 设计非阻塞、可维护的固件。
- 能定位 HardFault、栈溢出、I2C 锁死、通信丢包和竞态问题。
- 能完成 MCU、边缘网关、MQTT 和 Web 仪表盘的全链路项目。
- 能用嵌入式岗位语言表达项目经验，应对初中级岗位面试。
