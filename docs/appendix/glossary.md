# 术语表

| 术语 | 含义 |
| --- | --- |
| MCU | 微控制器，集成 CPU、Flash、SRAM 和外设 |
| SoC | 片上系统，通常集成 CPU、GPU、外设和存储控制器 |
| HAL | 硬件抽象层 |
| LL | 低层库，接近寄存器的薄封装 |
| BSP | 板级支持包，负责具体板卡的初始化 |
| RTOS | 实时操作系统 |
| ISR | 中断服务程序 |
| NVIC | Cortex-M 中断控制器 |
| EXTI | 外部中断 |
| DMA | 直接内存访问 |
| PWM | 脉冲宽度调制 |
| ADC/DAC | 模数/数模转换 |
| UART | 通用异步收发器 |
| I2C | 两线制同步串行总线 |
| SPI | 四线制同步串行总线 |
| CAN | 控制器局域网 |
| MQTT | 轻量级发布/订阅消息协议 |
| TLS | 传输层安全协议 |
| OTA | 空中升级 |
| Bootloader | 启动加载程序 |
| DTB | 设备树二进制 |
| Rootfs | 根文件系统 |
| sysroot | 交叉编译使用的目标系统头文件和库 |
| ABI | 应用二进制接口 |
| ELF | 可执行与可链接格式 |
| MAP | 链接映射文件 |
| RMW | 读改写操作 |
| FMEA | 失效模式与影响分析 |
| HIL | 硬件在环测试 |
| LWT | MQTT 遗嘱消息 |
| QoS | MQTT 服务质量等级 |
| BLE | 低功耗蓝牙 |
| GATT | BLE 属性协议的服务/特征模型 |
| A/B 分区 | 双系统分区升级方案 |
| 优先级反转 | 高优先级任务被低优先级任务间接阻塞 |
| 优先级继承 | 持有锁的低优先级任务临时继承高优先级 |
| 栈高水位 | 任务栈历史最小剩余空间 |
| 临界区 | 不允许被打断的代码段 |
| 内存屏障 | 约束编译器和 CPU 重排的机制 |
