# 排障手册

## 通用流程

1. 记录现象、时间、环境、版本。
2. 确认影响范围：单机/批量、特定温度/网络/批次。
3. 分层定位：电源 → 时钟/复位 → 启动 → 驱动 → 任务 → 协议 → 应用。
4. 每次只改一个变量。
5. 保留日志和现场。
6. 修复后加回归测试。

## 上电不工作

- 电源电压、电流、短路。
- 复位脚、Boot 引脚、晶振。
- 调试器能否连接。
- 串口是否有启动日志。
- 程序是否进入 HardFault。

## 随机复位

- 读取复位原因。
- 看门狗是否被正确喂。
- 电源峰值电流和欠压。
- 栈溢出/数组越界。
- 温度、通信、任务饿死。
- 记录运行时长和复现条件。

## 串口乱码/无输出

- 波特率、数据位、校验、停止位。
- TX/RX 是否接反。
- 电平是否兼容。
- 引脚复用和时钟是否使能。
- 发送缓冲区长度和重定向。

## I2C 失败

- 上拉电阻和上升沿。
- 7 位/8 位地址。
- 总线是否被拉低。
- 从设备供电和上电等待。
- 时钟拉伸、速率、线长。
- 9 个时钟脉冲恢复总线。

## SPI 读回全 0/全 1

- CPOL/CPHA、位序。
- CS 时序和片选。
- 时钟是否超过从设备上限。
- MISO/MOSI 接反。
- 多从机 MISO 冲突。

## RTOS 卡死

- 暂停调试器看任务状态。
- 检查死锁、优先级反转、忙等。
- 队列是否满、等待是否无限。
- 中断是否风暴。
- 栈高水位。

## 网络问题

- IP、网关、DNS。
- TLS 证书和时间。
- Broker 地址/端口/主题。
- 重连、订阅、QoS。
- 抓包和 Broker 日志。

## OTA 失败

- 镜像签名/哈希/版本。
- 分区和启动标志。
- 断电恢复。
- 新固件启动自检。
- 回滚镜像是否完整。

## Linux 服务失败

```bash
systemctl status app
journalctl -u app -b
strace -f -p <pid>
lsof -p <pid>
```

检查依赖、权限、工作目录、只读文件系统、端口占用。
