# 学习方法

## 先建立因果链

嵌入式知识不能只背结论。每学一个外设，都按下面的因果链记录：

1. 硬件引脚如何连接。
2. 时钟和电源是否使能。
3. 寄存器或 HAL 配置了什么。
4. 中断、DMA 或轮询如何触发。
5. 数据如何被读取、校验和消费。
6. 出错时如何观测和恢复。

## 每节完成四件事

- 写一个最小可运行示例。
- 用调试器或逻辑分析仪观察真实行为。
- 故意制造一个故障并修复。
- 用 3 分钟向别人解释原理和取舍。

## 前端经验的正确用法

把前端概念当作类比，不要当作替代。事件循环可以帮助理解调度，但不能代替对中断优先级、临界区和内存占用的理解。

## 记录排障日志

每次遇到问题，记录现象、假设、验证过程、根因和修复方式。三个月后，这份日志比任何速查表都更有价值。
