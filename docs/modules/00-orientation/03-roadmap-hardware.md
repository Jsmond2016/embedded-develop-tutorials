# 0.3 学习路线、硬件清单与实验安全

> 本节目标：知道买什么、为什么买、如何安全地搭起实验台，并建立 20–24 周的执行节奏。

## 推荐配置

### 主控板

首选 `NUCLEO-F411RE`：

- Cortex-M4，100 MHz，512 KB Flash，128 KB SRAM。
- 板载 ST-Link，省去独立调试器。
- 引脚排针友好，适合面包板和逻辑分析仪。
- 资源足够从裸机学到 FreeRTOS、协议栈和简单 GUI。

预算替代：`STM32F103C8T6` 最小系统板 + `ST-Link V2`。它便宜、资料多，但需要确认克隆芯片和接线，调试体验不如 NUCLEO。

### 联网与 Linux

- 联网：`ESP32-S3` 开发板，用于 Wi-Fi/BLE、ESP-IDF 和 MQTT。
- Linux：`Raspberry Pi 4B/5`，建议 2 GB 以上内存。
- 预算有限：Linux 实验使用 `QEMU`，但 GPIO 和真实外设实验仍需开发板。

### 基础工具

| 工具 | 用途 | 优先级 |
| --- | --- | --- |
| 面包板与杜邦线 | 快速搭建电路 | 必须 |
| 万用表 | 测电压、通断、电流 | 必须 |
| USB-TTL | 串口日志与调试 | 必须 |
| LED、按键、电阻 | GPIO 入门 | 必须 |
| I2C OLED | 观察状态与调试信息 | 强烈推荐 |
| AHT20/BME280 | 温湿度/气压采集 | 强烈推荐 |
| 逻辑分析仪 | 看 UART/I2C/SPI 时序 | 推荐 |
| 示波器 | 看模拟波形与电源质量 | 可选 |
| CAN 收发器 | CAN 实验 | 进阶可选 |

不要一次买齐所有模块。先完成第 0–2 部分，再按项目需要补外设。硬件不是收藏品，能完成实验的最小集合就是最好的集合。

## 实验台布置

1. 桌面保持干燥、整洁，开发板放在防静电垫或绝缘表面。
2. 接线前断电，改线后再上电。
3. 电源、地、信号线使用不同颜色，至少做到心里有数。
4. 逻辑分析仪和开发板共地，但不要用万用表电流档直接测电源两端。
5. 所有实验使用 3.3 V 或 5 V 低压直流。

::: danger 安全边界
不要接触市电、高压、电机驱动、大功率电池和没有隔离措施的电路。不要用开发板直接驱动电机、继电器或大电流负载。涉及市电的设备必须由具备资质的人员设计和验收。
:::

## 20–24 周执行节奏

| 周次 | 重点 | 周末产出 |
| --- | --- | --- |
| 1 | 环境与第一个固件 | 可烧录、可调试的点灯工程 |
| 2–5 | C 与主机端测试 | 环形缓冲区 + 命令解析器 |
| 6–10 | MCU 外设 | 裸机监测节点 |
| 11–14 | FreeRTOS | 多任务监测仪 |
| 15–17 | 通信与 IoT | MQTT 全链路 Demo |
| 18–20 | 嵌入式 Linux | 交叉编译与网关服务 |
| 21–22 | 工程化 | 测试、CI、OTA、文档 |
| 23–24 | 求职 | 简历、作品集、模拟面试 |

如果每周只能投入 8 小时，可以把周期拉长到 30–36 周，但不要删掉动手实验。嵌入式能力主要来自调试经验，而不是阅读速度。

## 采购策略

- 优先购买带官方调试器的开发板，减少“板子坏了还是线接错了”的干扰。
- 传感器优先选有公开数据手册、寄存器说明和成熟驱动的型号。
- 不买来源不明的“万能套件”，按课程实验逐个补齐。
- 保留购买链接、原理图、示例代码和芯片丝印照片，方便复盘。

## 动手练习

列出你已经拥有的器材、需要购买的器材和预算。把器材分成“第 0–2 部分必需”和“后续项目再买”两栏，只购买第一栏。
