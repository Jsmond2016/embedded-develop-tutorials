# P5 综合项目：低功耗环境监测终端

## 产品目标

设计一个电池供电的环境监测终端：

- 每 60 秒采集温湿度。
- 通过 Wi-Fi/MQTT 上报。
- 支持 BLE 配网。
- 断网缓存 24 小时。
- OTA 升级与回滚。
- 电池续航目标 30 天。

## 系统边界

```text
传感器 -> MCU -> Wi-Fi -> MQTT -> 云端 -> Web
             -> BLE 配网
             -> 本地缓存
             -> OTA
```

## 核心指标

| 指标 | 目标 |
| --- | --- |
| 平均电流 | < 1 mA |
| 续航 | > 30 天 |
| 端到端延迟 | < 2 s |
| CPU 占用 | < 70% |
| 栈余量 | > 20% |
| 断网缓存 | 24 h |
| OTA 回滚 | < 1 次重启 |
