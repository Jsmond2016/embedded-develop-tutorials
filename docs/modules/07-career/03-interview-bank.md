# 7.3 嵌入式面试题库

> 本节目标：不仅知道答案，还能结合项目说明取舍和踩坑。

## C 与内存

### 1. `volatile` 的作用是什么？

告诉编译器该变量可能在程序之外改变，不能缓存或优化掉访问。它不保证原子性，也不替代锁。

### 2. 栈和堆的区别？

栈自动分配、速度快、空间小；堆手动分配、灵活但可能碎片化、延迟不确定。实时系统优先静态分配。

### 3. `static` 的作用？

修饰局部变量：生命周期变为整个程序；修饰全局变量/函数：限制链接可见性到当前编译单元。

### 4. 结构体为什么会有填充？

为了满足字段对齐要求，提高访问效率。字段顺序影响大小，协议传输应显式序列化。

### 5. 指针和数组的区别？

数组名在表达式中常退化为首元素指针，但数组有确定的存储大小；函数参数中的数组会退化成指针，必须额外传长度。

### 6. 什么是未定义行为？

语言标准不规定结果的行为，例如有符号溢出、越界访问、解引用空指针。优化后可能表现出难以复现的问题。

## 中断与启动

### 7. 中断服务程序应该遵循什么原则？

短小、不阻塞、不清洗大量逻辑、不调用不可重入函数；确认来源、清标志、投递事件，重活放到任务。

### 8. 中断优先级如何设计？

按响应紧迫程度，而不是代码重要性。安全/故障最高，高速通信次之，按键/显示较低。还要遵守 RTOS 的可管理优先级范围。

### 9. 上电后程序如何进入 `main`？

从向量表取初始 MSP 和 Reset_Handler，启动代码初始化时钟、复制 `.data`、清零 `.bss`、初始化 C 库，再调用 `main`。

### 10. HardFault 如何定位？

查看 CFSR/HFSR/MMFAR/BFAR、出错 PC/LR 和栈帧，结合 Map 文件、反汇编和日志判断空指针、越界、栈溢出或非法指令。

## RTOS

### 11. 任务和中断的区别？

任务是调度器管理的执行流，有独立栈，可阻塞；中断由硬件触发，运行在 Handler mode，必须短小且不能调用阻塞 API。

### 12. 队列、信号量、互斥量的区别？

队列传数据；信号量发事件/计数；互斥量保护共享资源并支持优先级继承。

### 13. 优先级反转是什么？

高优先级任务等待低优先级任务持有的锁，而中优先级任务抢占低优先级任务，导致高优先级被间接阻塞。用互斥量的优先级继承缓解。

### 14. 如何判断任务栈是否够用？

用 `uxTaskGetStackHighWaterMark` 测最坏剩余栈，结合最深调用链和中断嵌套，保留 20–30% 余量。

### 15. 为什么中断里要用 `FromISR` API？

普通 API 可能阻塞并操作调度器状态，ISR 上下文不能阻塞，必须使用专门的 FromISR 版本并处理是否需要任务切换。

## 通信

### 16. UART、I2C、SPI 如何选？

UART 点对点简单；I2C 线少、多从机、速率中低；SPI 速率高、线多、适合屏幕/Flash。

### 17. I2C 总线锁死怎么恢复？

检查上拉和地址；若从设备拉低 SDA，可把 SCL 配为开漏，手动发 9 个时钟并发送 STOP，再重新初始化总线。

### 18. TCP 可靠，为什么应用还要重试？

TCP 只保证连接内字节流可靠；断网、半开连接、服务端处理失败、业务超时都需要应用层 ACK、幂等和重试。

### 19. MQTT QoS 1 会重复吗？

会。QoS 1 是“至少一次”，接收方需要按消息 ID 或业务键去重。

### 20. OTA 如何防止变砖？

A/B 分区、签名校验、写入备用区、启动尝试计数、自检确认、失败回滚、串口恢复模式。

## 硬件与 Linux

### 21. GPIO 推挽和开漏的区别？

推挽能主动输出高/低；开漏只能拉低，需要外部上拉，适合 I2C 和共享总线。

### 22. 如何计算 LED 限流电阻？

`R = (Vcc - Vf) / I`。例如 3.3 V、1.8 V 压降、5 mA，约 300 Ω，选 330 Ω。

### 23. 交叉编译是什么？

在 host 上生成 target 架构的可执行文件，需要匹配的工具链和 sysroot。

### 24. 设备树的作用？

把板级硬件描述从内核代码中分离，驱动通过 `compatible` 匹配节点并读取资源。

### 25. 内核模块和用户空间程序的区别？

模块运行在内核空间，权限最高，错误可能导致 panic；用户程序有进程隔离，通过系统调用/设备节点访问硬件。
